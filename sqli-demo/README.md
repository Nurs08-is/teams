# SQL Injection демо: осал vs қорғалған

Бұл екі кішкентай Flask қосымшасы бір дерекқорды (users.db) қолданады,
бірақ кіру формасы екі түрлі жазылған: бірі осал, екіншісі қорғалған.

## Орнату

```bash
pip install flask
python setup_db.py
```

## Осал нұсқаны іске қосу

```bash
python vulnerable_app.py
```
Браузерде: http://127.0.0.1:5001

**Шабуыл сынау:**
- Email: `' OR 1=1--`
- Password: кез келген мәтін

Нәтижесінде парольсіз-ақ admin ретінде кіресіз. Беттің өзінде қандай SQL
сұранысы орындалғаны көрінеді, сол жерде `1=1` шарты қалай жұмыс істегенін
көруге болады.

## Қорғалған нұсқаны іске қосу

Бірінші терминалды жаппай, жаңа терминалда:
```bash
python secure_app.py
```
Браузерде: http://127.0.0.1:5002

**Сол шабуылды қайталап көріңіз:**
- Email: `' OR 1=1--`
- Password: кез келген мәтін

Бұл жолы кіру сәтсіз болады: "Email немесе пароль қате" дейді, себебі бүкіл
мәтін SQL команда ретінде емес, жай іздеу мәні ретінде өтеді.

## Дұрыс кіру (екі нұсқада да жұмыс істейді)

- Email: `admin@shop.kz`
- Password: `AdminSecret123`

## Қорытынды

| | Осал нұсқа | Қорғалған нұсқа |
|---|---|---|
| Код | `f"...email='{email}'..."` | `"...email=?...", (email, password)` |
| `' OR 1=1--` шабуылы | Өтеді (admin болып кіреді) | Өтпейді |
| Себебі | Мәтін тікелей SQL-ге қосылады | Мәтін бөлек параметр ретінде беріледі |
